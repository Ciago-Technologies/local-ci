# The demo

The 30-second aha moment, two ways:

1. **Run it:** `./scripts/demo.sh` — builds localci, diffs the
   laptop vs CI fixtures, shows the workflow-aware filter (7 raw
   differences → 3 that matter), then shows the `localci run`
   command that reproduces the failing step. No Docker needed.
2. **Watch it:** the animated GIF in the README
   (`docs/demo.gif`), generated by `scripts/make-demo-gif.py`
   (Pillow + DejaVu Sans Mono, no screen recording).

Regenerate the GIF after changing the demo script:

```sh
python3 scripts/make-demo-gif.py docs/demo.gif
```
